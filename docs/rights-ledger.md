## Rights requested

Each request should explicitly cover:

- reproduction of the selected problem data and necessary wording;
- interactive adaptation and altered layout;
- progressive hints, automated answer checking, and explanatory solutions;
- public, worldwide web distribution through Cloudflare Pages;
- inclusion in a public GitHub repository;
- non-commercial educational use;
- the required attribution wording; and
- whether the organisation can authorise the named author’s contribution or an additional author approval is required.

## Response procedure

- If permission is granted, preserve the response and update both this ledger and `THIRD_PARTY_CONTENT.md` with its exact scope and conditions.
- If permission is limited, disable uses outside the granted scope.
- If permission is declined or removal is requested, remove the affected adaptation from the deployed site and default branch, then replace it with independently authored content.
- Silence is not approval; keep the status marked as pending until an authorised party responds.
